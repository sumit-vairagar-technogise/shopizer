## 🎓 Learning Objectives

After completing this onboarding, you will:

✅ Understand what Shopizer is and its capabilities
✅ Know the technology stack and why each technology is used
✅ Understand the layered architecture
✅ Navigate the multi-module project structure
✅ Run the application locally

✅ Trace requests from API to database

✅ Know where to find specific functionality
✅ Be able to make code changes confidently
